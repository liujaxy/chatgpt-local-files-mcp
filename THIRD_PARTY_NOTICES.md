# Third-party components

The official [OpenAI tunnel-client](https://github.com/openai/tunnel-client) is pinned to v0.0.14. Its Apache-2.0 LICENSE, NOTICE, and Windows amd64 distribution dependency license notices are retained under vendor/tunnel/. These apply to upstream components, not automatically to this project's code.

Executable files are not distributed in this source repository. Download the official release and verify the ZIP checksum as described in README.md. Release metadata and the checksum list are retained under vendor/. The unused Cloudflare runtime is not distributed here.

Python packages are installed separately from requirements.lock.txt and retain their upstream licenses. A future bundled application must review and include applicable dependency notices.
